# Mat Assombrado

Jogo digital educacional desenvolvido em RPG Maker – IFBA.

▶️ **Jogue no navegador:** https://celsoedu-del.github.io/mat-assombrado/

## Créditos

**Autores:** Cristiane Bertolino, Gabriel Santana, Luiz Henrique, Suelem Souza e Staylana Salles

Conteúdo: Análise Combinatória (Princípio Fundamental da Contagem, permutação simples e arranjo simples).

Uso educacional, não comercial. Os salvamentos ficam guardados no próprio navegador.
